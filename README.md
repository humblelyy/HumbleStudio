# HUMBLE STUDIO

Responsive, GitHub Pages-ready HUMBLE STUDIO website.

## Change tool thumbnails
Replace these files with your own screenshots/images (keep the filenames):
- `assets/tools/humble-studio-tool.png`
- `assets/tools/humble-ae-downgrader.png`

Any normal PNG/JPG/WebP image works. For best results use a 16:9 screenshot around 1600x900.

## Main files
- `index.html` — homepage
- `style.css` — design, responsive layout and animations
- `script.js` — interactions, cursor, transitions and reveals
- `assets/logo/` — supplied HUMBLE logos
- `assets/tools/` — tool thumbnail slots
- `tools/` — individual tool landing pages

## Local test
Open `index.html` in a browser. For the cleanest test, use a local server such as VS Code Live Server.

## GitHub Pages
Upload the contents of this folder to a GitHub repository, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
